1. Hardware Baseline:

- Number of CPU Cores: 2
- Total RAM: 7.76 GB

2. Observation (from htop during stress test):
During the CPU stress test, I observed in htop that the Python script did 
not utilize 100% of all available CPU cores. Instead, it heavily utilized 
only a single core (Core 1 was running at around 95.3%, while Core 0 had 
very low usage). This clearly demonstrates the limitation of Python's 
single-thread execution.

3. Analysis:
Knowing the OS memory limits is crucial because loading a massive dataset 
of 500,000 images all at once could exceed the available RAM, causing the 
program to crash (Out of Memory error). Additionally, knowing the CPU core 
count allows us to write optimized training code that utilizes parallel 
processing to distribute the workload across all available cores, rather 
than getting bottlenecked by a single core, which significantly reduces 
the training time.
